# NX20 Header 1000..1008 semantic registry

Status: **finalized for StepNX Studio** (2026-09-01).

This document is the canonical StepNX Studio reference for the later-generation
NX20 Header IDs 1000..1008. In the table below, **all** means **Fiesta and later**.
NXA does **not** use the Header 1000+ namespace. Same-number Split or Division
metadata is a separate scope and must not inherit these meanings.

| Header | Versions | Values | Name | Meaning |
| ---: | --- | --- | --- | --- |
| 1000 | Fiesta+ | `1..?` | Section | Section in which the chart is available. `1 = Arcade`. Values above 1 may have version-specific meanings. |
| 1001 | Fiesta+ | `1..50` | Difficulty | Chart level. Fiesta through Fiesta 2 Quest Zone uses the separate mission difficulty scale `1..8`. Level 50 is used as the special `??` display level by supported arcade versions. |
| 1002 | Fiesta+ | `1..5` | Players | Expected player count. Prime through R!SE expose Arcade charts with values above 1 as Co-Op content when Header1000 is 1. R!SE names the field `mpPlayers`. |
| 1003 | Fiesta..Fiesta 2 | pointer/reference | Paired Chart | Additional chart loaded for Player 2 by the Fiesta-series Co-Op implementation. Later engines retain parser support. |
| 1004 | Fiesta+ | bool | New Chart | Displays the `NEW` classification on the chart in the Select Screen/catalog UI. |
| 1005 | Fiesta+ | bool | Lock | Marks a chart as exclusive to a restricted selection path, notably Quest/Music Train. This Header is **not Auto Velocity**. |
| 1006 | Fiesta..Fiesta 2 | bool | Another | Displays the `Another` classification on the chart in the Select Screen. Retired after Fiesta 2. |
| 1007 | Prime..XX | bool | AM.PASS | Marks a chart as exclusive through AM.PASS. |
| 1008 | XX..R!SE | pointer/reference | Step Artist | Points to the Step Artist string displayed by modern Select Screen UI. R!SE names the field `mpStepArtist`. |

## Scope rules

Header IDs are scoped metadata. A numeric collision does not imply shared
semantics across Header, Split, and Division metadata. The most important example
is ID 1005: Prime 2 contains a separate gameplay/event-side ID 1005 in speed/timing
code, which explains the historical Auto Velocity misidentification. Header1005
itself is boolean and belongs to the Lock/catalog classification family.

The same rule applies to the discarded Prime 2 mission Division IDs 1005..1007:
they remain unrelated raw Division fields and do not inherit the Header meanings
above.

## Evidence summary

The finalized names combine official corpus structure, LIST/catalog correlation,
selection-screen behavior, executable consumers, and the modern R!SE metadata
enum. In particular:

- Fiesta 2 LIST flags correlate Header1004 with the NEW class, Header1005 with the
  locked/special-selection class, and Header1006 with Another.
- Prime 2 corpus uses Header1004, Header1005, and Header1007 as boolean flags;
  Header1006 is absent.
- Prime 2 Header1007 identifies the AM.PASS-exclusive chart population.
- R!SE explicitly names Header1002 `mpPlayers`, Header1003 `mp2PStep`, and
  Header1008 `mpStepArtist`; the legacy catalog-classification IDs 1004..1007 are
  absent from its modern typed enum.
- NXA has no Header1000+ family. StepNX Studio must therefore never expose these
  definitions through the native NXA profile.

## Studio behavior

Typed creation uses the ranges above while raw values remain losslessly
preservable. Version-specific legacy fields may remain recognizable in a broader
engine-family profile for round-trip safety even when typed creation is disabled
for versions that no longer use them. Trailer pointers/references continue to use
the guarded trailer editor rather than numeric normalization.
